# Bibliothèque littéraire

Catalogue de 223 œuvres : recherche, filtres, fiches détaillées, comparateur, exploration par thème, bibliothèque personnelle (localStorage).

Application autonome : `index.html` contient tout (HTML, CSS, JavaScript et données). Aucune installation nécessaire : ouvrez le fichier dans un navigateur.

## Ajouter des œuvres
Dans `index.html`, ajoutez un objet dans la liste `DATA` avec les champs : id, titre, auteur, categorie, genre, annee, pages, origine, resume, themes, concepts, difficulte, interet_oral, wikipedia_url, source_url (facultatifs : titre_original, langue, mouvement, verif).

## Mise en ligne (GitHub Pages)
Settings > Pages > Deploy from a branch > `main` / racine.
