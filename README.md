# Bibliothèque littéraire

Catalogue de 117 œuvres : recherche, filtres, fiches, comparateur, exploration par thème, bibliothèque personnelle (localStorage).

Application autonome : `index.html` contient tout (HTML, CSS, JS et données). Aucune installation nécessaire, ouvrez le fichier dans un navigateur.

## Ajouter des œuvres
Dans `index.html`, ajoutez un objet dans la liste `DATA` avec les champs : id, titre, auteur, categorie, genre, annee, pages, origine, resume, themes, concepts, difficulte, interet_oral, wikipedia_url, source_url. `catalogue_litteraire_bac.json` est la copie de référence des données.

## Mise en ligne (GitHub Pages)
Settings > Pages > Deploy from a branch > `main` / racine.
